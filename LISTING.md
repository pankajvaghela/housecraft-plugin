Give your coding agent floor plans, photos, or measurements to build an editable model of one single-level home. Label estimates, preserve the existing layout, and compare renovation variants in a localhost browser preview. Furniture appears as dimensioned boxes. HouseCraft needs desktop execution with Git, Node.js 22 or later, npm, and a WebGL browser. It uses the separate open-source [HouseCraft Viewer](https://github.com/pankajvaghela/housecraft-viewer) and needs no HouseCraft account. Renovation concepts do not assess structural feasibility.

Starter prompts:

- Set up HouseCraft and check whether my computer can run the local preview.
- Model my single-level home from these measurements. Ask for missing dimensions and label estimates.
- Add a variant with the dining table by the window and keep the existing layout unchanged.

This is listing copy for future submission, not a directory listing. The OpenAI package is skills-only and desktop-only. It has no HouseCraft service or bundled MCP server. The agent host can process files you share according to its own settings. Before submitting, publish the pinned viewer release and test setup and model creation in a clean desktop install.
