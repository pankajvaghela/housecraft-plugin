# Changelog

## 0.1.1

- Added a privacy policy and linked it from both plugin manifests.
- Documented local setup effects, model storage and agent-provider data handling.

## 0.1.0

- Added the `housecraft:setup` skill to check local prerequisites and set up the separate HouseCraft Viewer at a pinned revision.
- Added the `housecraft:create-house` skill to model one home from plans, photos, or measurements and add editable renovation variants while preserving the existing layout.
- Added Claude Code and portable Agent Plugins manifests, marketplace entries and listing assets.
- Preview uses the localhost viewer and dimensioned furniture boxes. No HouseCraft account or hosted HouseCraft service is required.
